RPM AREA V28 — ANALISIS LENGKAP
===============================

FITUR BARU (tanpa SQL baru):
- Dashboard: proyeksi POINT akhir minggu, kebutuhan QTY dan NS per hari, perbandingan dengan hari sebelumnya.
- Dashboard: ranking toko, filter brand, analisis brand tertinggal dan peringatan.
- Dashboard: salin atau bagikan laporan WhatsApp berdasarkan tanggal pilihan.
- Tab Target: Smart Target Advisor (PLU efisiensi tinggi, alternatif dan campuran 2–3 PLU). Semua rekomendasi hanya simulasi.
- Tab Input: deteksi potensi PLU ganda, HPP 0, QTY tidak valid dan lonjakan tidak wajar.
- Supabase, sinkronisasi aman, kuota V27 dan template PNG tetap dipertahankan.

CARA PEMASANGAN
1. BACKUP JSON DARI SETIAP HP, dan siapkan salinan ZIP lama sebelum mengganti versi.
2. Unggah semua isi folder RpmArea-main (termasuk insights.js, insights.css) ke root repository GitHub Pages.
3. Reload halaman aplikasi, jika tampilan masih lama tutup/buka kembali dan refresh service worker.
4. Pilih minggu/tanggal lalu buka Home untuk analisis, Target untuk advisor, Input untuk kualitas data.
5. Pastikan data dua perangkat benar-benar sama dengan Backup JSON dan tes sinkronisasi Supabase.

PENTING:
- Tanpa perubahan SQL baru. SQL kuota V27 yang sudah dipasang tetap dipakai.
- Ini bukan AI eksternal; saran dihitung dari target, QTY dan NS/HPP yang tersimpan.
- Saran tidak mengetahui stok, tren pelanggan atau harga transaksi aktual.
- Pada proyeksi tanggal masa depan belum ada prediksi, pilih tanggal hari ini/kemarin.
- Laporan WhatsApp bukan pesan terkirim otomatis; pengguna tetap memilih kontak dan mengirim.
- Tidak ada jaminan PLU tertentu benar-benar dapat terjual sebanyak rekomendasi.
- ZIP ini tidak termasuk APK Android.
- Periksa kuota dan audit cloud terpisah; fitur analisis V28 tidak membuat tabel/kueri cloud tambahan.
