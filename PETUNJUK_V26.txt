RPM AREA V26 — TARGET 100% PER TOKO, BRAND & PLU

1. Back up data JSON dari HP sebelum pembaruan.
2. Unggah file di dalam folder RpmArea-main ke root website (GitHub Pages), termasuk index.html, app.js, style.css, sw.js.
3. Di navigasi baru pilih Target. Pilih toko dan brand, lihat kekurangan QTY dan NS serta POINT.
4. Pada tabel PLU, masukkan "Rencana tambahan" untuk simulasi. Tombol Saran mengisi kebutuhan jumlah unit pada satu PLU berdasarkan HPP-nya.
5. Simulasi tidak mengubah data asli. Hanya tombol "Simpan tambahan QTY" (dengan konfirmasi) yang menambahkan QTY ke hari dipilih.
6. Target brand memerlukan hasil import Excel TARGET PERTOKO. Jika belum ada target brand, aplikasi tidak mengarang estimasi.
7. Angka mengikuti tanggal pilihan pada Home. Jika ingin perubahan tanggal, kembali ke Home lalu pilih tanggal.
8. Fitur Supabase, status cloud dan kuota V25 tetap ada. Tidak perlu SQL baru untuk V26.
9. Draft simulasi hanya disimpan sementara selama halaman masih terbuka, tidak dibagikan ke Supabase.
10. Pastikan sinkronisasi antar perangkat sudah diuji sebelum menghapus aplikasi versi lama.

Rumus: POINT = 50*(QTY_aktual/Target_QTY + NS_aktual/Target_NS).
Tambahan satu PLU dengan HPP P dan Q unit menaikkan QTY sebesar Q, dan NS sebesar Q x P.
Target 100% POINT dihitung tanpa memaksakan masing-masing komponen harus sama-sama 100%.
