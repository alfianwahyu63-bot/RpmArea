RpmArea / SalesPulse Area - Pembaruan UI v7 (3 November 2026)
=============================================================

APA YANG BARU
- UI gelap modern (tema Neon Lime, Electric Violet, Coral Night, Cyber Blue,
  serta pilihan tema lama).
- Menu Pengaturan di navigasi, menjadi bottom navigation pada HP.
- Pengaturan > Tema & Gaya: ganti warna, glow, atau mode ringkas.
- Pengaturan > Edit Teks: lebih dari 70 label di dashboard dapat diubah
  atau dikosongkan (toggle Tampil), disertai pencarian dan reset per label.
- Pengaturan > Tampil / Sembunyi: sembunyikan banner, filter, kartu KPI,
  resume, grafik, scorecard, footer, atau kartu tertentu.
- Simpan otomatis pengaturan ke data lokal. Teks dan layout ikut masuk
  dalam backup JSON serta konfigurasi Cloud Firebase yang sudah tersedia.
- Tampilan responsif desktop dan ponsel (termasuk bottom navigation).

YANG DIPERTAHANKAN
- Formula POINT QTY 50% + NS 50%, TF Senin–Minggu, dan data tiap toko.
- Input PLU per hari & impor teks WhatsApp.
- Upload Excel / HPP / target, backup/restore, CSV, dan export PNG.
- File firebase-config.js dan cloud.js yang sebelumnya digunakan.
- Storage key salespulse_area12_v1 tetap sama; data browser lama dapat
  dibaca tanpa migrasi atau menghapus storage.

CARA MEMASANG KE GITHUB PAGES
1. Sebelum update, buka versi lama -> Master Toko & Excel -> Backup JSON.
2. Buka repository RpmArea di GitHub.
3. Upload / replace semua file dari dalam folder RpmArea-main ini
   ke ROOT repository, terutama index.html, app.js, style.css dan sw.js.
4. Commit perubahan.
5. Buka situs PWA dalam browser, refresh satu/dua kali agar cache service
   worker v7 ikut terbarui. Bila masih versi lama, tutup dan buka lagi.
6. Klik Pengaturan (ikon roda gigi) untuk mengubah teks atau tema.

CATATAN
- Mengubah teks label tidak mengubah nilai QTY, NS, POINT, dan data toko.
- Mengubah nama toko/data master tetap lewat menu Master Toko & Excel.
- Tema perangkat disimpan lokal agar setiap HP dapat memilih warna sendiri.
- Penyesuaian teks dan visibility disimpan dalam settings; ketika Firebase
  aktif dan pengguna berhak edit, setting dapat tersinkron ke perangkat tim.
- Jika memilih reset teks/layout, data penjualan tetap disimpan.
- Untuk keamanan selalu backup JSON terlebih dahulu sebelum deployment.
