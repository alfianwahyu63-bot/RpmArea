RpmArea V17: Sinkronisasi Ulang Aman

1. Tetap simpan file Backup Lokal dan Backup Cloud yang sudah ada. Backup ulang di menu Cloud sebelum melakukan perbaikan.
2. Upload isi folder RpmArea-main V17 ke repository GitHub. Jangan menghapus data PWA atau cache aplikasi secara manual.
3. Buka aplikasi pada HP yang memiliki QTY lokal terlengkap, dan masuk ke Cloud.
4. Saat ada perbedaan, tap "🔄 Sinkronisasi Ulang Aman".
5. Sistem mengambil ulang data server. Jika perbedaan bisa digabung, baca RINCIAN yang muncul pada dialog konfirmasi.
6. Konfirmasi HANYA jika QTY lokal dan cloud benar serta 0 bukan koreksi yang disengaja.
7. Sistem menyimpan backup, menulis hanya dokumen berbeda yang aman, lalu memeriksa ulang seluruh data.
8. Pastikan status "SINKRON ULANG BERHASIL"/"Cloud: Aktif". Buat backup JSON terbaru.

Jika tombol menampilkan konflik yang tidak bisa digabung:
- JANGAN hapus data, uninstall PWA, restore, atau menimpa cloud.
- Unduh Backup Lokal dan Backup Cloud terbaru, lalu periksa perbedaannya sebelum mengizinkan perbaikan khusus.
- Hindari input simultan dari HP lain selama penggabungan.

Perlindungan: QTY positif yang berbeda pada hari yang sama tidak otomatis dipilih. Target/HPP/PLU berbeda juga ditahan.
