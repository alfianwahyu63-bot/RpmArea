RPM AREA V24 — PERBAIKAN TIME FACTOR & TEMPLATE PNG

1. Tata letak Time Factor di HP dirapikan: persentase, navigasi tanggal, kembali hari ini, dan keterangan terpisah.

4. File changelog dan panduan lama telah dibuang. File pemulihan Firebase tetap ada agar migrasi data lama aman.

6. Penting: backup data lokal tiap HP sebelum upgrade. Pastikan login & sinkronisasi Supabase normal sebelum hapus data lama.
7. Untuk pemasangan ala APK: website sudah menggunakan manifest PWA. Di Chrome Android, buka aplikasi lalu menu (⋮) > Tambahkan ke Layar Utama/Instal Aplikasi.
8. Untuk APK yang sebenarnya perlu build Android melalui Capacitor + Android Studio/SDK. Tidak ada APK dalam ZIP ini.
